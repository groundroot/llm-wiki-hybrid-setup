# Vault Daily Review

## Purpose

사용자 기기(예: 노트북/데스크톱)의 옵시디언 볼트에서 새 노트·변경 노트를 매일 감지하고, 그 지식을 에이전트가 다시 쓸 수 있는 형태로 축적한다: 위키 통합 + 재사용 스킬/작업 흐름 후보 정리.

## 배치 전 설정 (플레이스홀더 교체)

- `<USER_VAULT_PATHS>`: 점검 대상 볼트들의 절대 경로 목록. 예: `/Users/<username>/Documents/MyVault`, `~/Sync/MyVault` 등. 클라우드 동기화 폴더(iCloud Drive, Dropbox 등) 아래에 있으면 기기가 오프라인이어도 동기화된 복사본을 읽을 수 있다.
- `<WIKI_VAULT_PATH>`: 에이전트 작업용 LLM 위키 볼트 경로. 예: `~/my-agent-wiki`.
- `<SKILLS_DIR>`: 에이전트의 스킬 디렉터리. 예: `~/workspace/skills`.
- `<MAC_OFFLINE_POLICY>`: 사용자 기기가 오프라인일 때의 동작(기본: 조용히 건너뛰고 짧게 보고).

## Tooling

- 사용자 기기의 파일에 접근할 수 있는 도구를 사용한다(예: 기기 파일 목록/읽기 커맨드, SSH, 동기화 폴더 직접 접근 등). 실행 시점에 접근 가능 여부를 먼저 확인한다.
- 위키: `<WIKI_VAULT_PATH>` (스키마 `<WIKI_VAULT_PATH>/_시스템/운영규칙.md`를 먼저 읽는다).

## Workflow

1. **상태 로드**: `<WIKI_VAULT_PATH>/_시스템/볼트점검상태.json`을 읽는다. 없으면 빈 상태로 시작한다. 구조: `{ "vaults": { "<볼트경로>": { "notes": { "<상대경로>": <mtime epoch> }, "last_checked": "<ISO>" } } }`
2. **변경 감지**: 각 볼트를 최대 3단계 깊이까지 순회하며 `.md` 파일의 경로와 수정 시각을 수집한다. 상태 파일과 비교해 신규·변경 노트를 추린다. 한 번에 처리할 노트는 최대 20개, 최신 수정 순으로 우선한다. 나머지는 다음 실행으로 미룬다(상태 파일에 처리한 것만 기록).
3. **내용 파악**: 신규·변경 노트를 읽는다. 본문에서 뽑을 것: 핵심 주장·지식, 재사용 가능한 절차(프롬프트, 체크리스트, 단계, 명령어), 기존 위키 페이지와의 연결점, 모순되는 기존 내용.
4. **위키 통합** (스키마의 ingest 규칙대로): 관련 위키 페이지를 갱신하거나 새 페이지를 만들고, `index.md`와 `log.md`(`## [YYYY-MM-DD] ingest | 볼트 데일리 리뷰`)를 갱신한다. 출처에 원본 노트 파일 경로를 명시한다.
5. **스킬/작업 흐름 후보 정리**: 반복 사용 가능한 패턴이 보이면 `_시스템/스킬 후보.md`에 후보로 기록한다(패턴 이름, 근거 노트, 예상 트리거, 만들 스킬 초안 한 줄). 같은 패턴이 이미 후보에 있거나 노트 2개 이상에서 반복되면, 실제로 스킬(`<SKILLS_DIR>/<이름>/SKILL.md`)을 만들고 후보에 "생성됨"으로 표시한다. 스킬을 만들었으면 보고에 반드시 포함한다.
6. **상태 저장**: 처리한 노트의 수정 시각을 상태 파일에 반영하고 `last_checked`를 갱신한다.
7. **보고**: 새 노트 수, 위키에 통합한 내용, 만든 스킬/후보를 짧게 보고한다. 새 노트가 없으면 한 줄로만 알린다.

## Operating Rules

- 사용자 기기의 볼트는 **읽기 전용**이다. 사용자가 명시 지시하지 않으면 사용자 파일을 절대 수정·삭제·이동하지 않는다.
- 비밀값이 들어 있을 수 있는 파일(credential, .env, 키 파일)은 읽지 않는다. 노트 본문에 비밀값이 보여도 위키·스킬에 옮기지 않는다.
- 사용자 기기가 오프라인이면 `<MAC_OFFLINE_POLICY>`를 따른다. 같은 실패를 반복 보고하지 않는다.
- 노트 내용을 사실로 단정하지 않는다. 사용자의 노트는 "사용자 노트 기준"으로 출처를 밝히고, 외부 사실 확인이 필요한 것은 미확인으로 표시한다.
- 처리량을 부풀리지 않는다: 읽지 않은 노트는 "확인함"으로 쓰지 않는다.
