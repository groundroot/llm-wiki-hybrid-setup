# 지속 발전 주제

사용자가 지정한, 에이전트가 계속 추가하고 발전시키는 지식 주제 목록이다.
주제 추가·삭제는 사용자 지시로만 한다.

| 주제 | 관련 위키 페이지 | 마지막 갱신 | 비고 |
|---|---|---|---|
| 예: (AI 도구 활용법) | [[10 위키/예시 주제 페이지]] | YYYY-MM-DD | 예: 매일 리서치로 새 활용법·사례를 출처와 함께 보강 |
| 예: (관심 분야 동향) | [[10 위키/예시 주제 페이지]] | YYYY-MM-DD | 예: 주 2회 정기 스윕으로 최신 동향 업데이트 |

## 운영 방식

- 대화에서 이 주제와 관련된 새 사실·결정·자료가 나오면, 해당 위키 페이지를 보강한다.
- 정기 리서치(예: 주 1회 새 자료 조사)는 사용자 승인 후 일정으로 돌린다.
