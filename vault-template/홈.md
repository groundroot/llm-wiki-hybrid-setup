# 내 LLM 위키

이 볼트는 AI 에이전트가 관리하는 LLM 위키다.
대화에서 나온 질문과 답, 결정, 사람, 프로젝트 정보가 서로 링크된 위키 페이지로 쌓인다.

## 입구

- 위키 인덱스: [[index]]
- 운영 규칙(스키마): [[_시스템/운영규칙]]
- 활동 로그: [[log]]

## 구조 (3층)

| 위치 | 용도 |
|---|---|
| `raw/` | 원본 소스 (불변, 절대 수정 안 함). 첨부는 `raw/assets/` |
| `10 위키` | 질문·답변이 정리된 위키 페이지 (핵심) |
| `20 사람` | 사람별 페이지 |
| `30 프로젝트` | 진행 중인 일별 페이지 |
| `00 받은편지함` | 아직 정리 안 된 메모, 던져 넣는 곳 |
| `90 아카이브` | 끝난 것들 |
| `_템플릿` | 노트 템플릿 |
| `_시스템` | 운영 규칙, 지정 주제 목록 |

## 사용법

- 에이전트에게 질문하면, 지식으로 남길 가치가 있는 답은 위키 페이지로 저장되고 index에 링크된다.
- "이거 위키에 넣어줘"라고 하면 무조건 저장한다.
- "위키에서 찾아줘"라고 하면 이 볼트에서 검색해 답한다.
- 원본 자료는 `raw/`에 넣고 "이거 ingest해줘"라고 하면 요약·연결까지 정리된다.
